````markdown

本次替换：<人物 / 产品 / 场景 / 都不换>
故事：<只换皮 / 借结构重写（方案 X，另外两个方案见下）>

## 一、结构拆解

- **钩子**：
- **结构公式**：A → B → C → D
- **节奏**：平均 X 秒一镜；哪里快、哪里慢
- **产品怎么进来的**：

|---|---|---|---|---|---|

拿不准的地方在格子里标（不确定）；漏切补上的切点写 ≈。表格下面一句话说明脚本切出几条、你手动拆开或合并了哪些。

### 运镜设计（导演逻辑）

只列关键时刻。

| 时刻 | 怎么拍 | 为什么这样拍 |
|---|---|---|

## 四、素材清单（生成前要准备好）

| 图 | 是什么 | 有了吗 | 用在 |
|---|---|---|---|
| 图A | 人物A · 角色卡（横） | ✅ `素材/人物A-角色卡.png` / ⬜ | 第 1、3 段 |
| 图C | 场景甲（竖） | ✅ / ⬜ | 第 1–6 段 |
| 声A | 人物A 的真声，10–15 秒（本人出镜才要） | ✅ `素材/人物A-声音.mp3` / ⬜ | 第 1、3 段 |
| 后制 | logo、产品截图 | ✅ `素材/logo.png` / ⬜ | 贴进第 X 段 |

没有的图，用图片模型照下面出（一行一张，搭 studio 画布的脚本会读这几行）：

- **图A**：「一张横版真实摄影的角色设定图，纯中灰色无缝背景……（照 character-sheet skill 的模板）」
- **图A**（输入：图P）：「……人物就是 @image1 这个人……」　← 用户给了本人照片（图P）时这样写
- **图D**（输入：图L）：「…印着 @image1 的 logo…」　← 要拿别的图当输入（图生图）时这样写，提示里照输入的顺序叫 @image1、@image2

人物一律先做横版三格角色卡（灰底：脸部特写 / 正面全身抹脸 / 背面全身），照 character-sheet skill 写；场景图照「场景图要像实拍」写。logo、产品照这类要放进画面的图，列成「图L」等一般的图（不要放在「后制」那行），才能当输入。

每段只接那一段用得到的图，编号在每段里从 @image1 重新排（见每段的「接图」）。

「有了吗」那格的档案路径要用反引号括起来，相对于这份 .md 所在的文件夹。

## 五、分段提示词

### 第 1 段 · 对应原片 0–13.5 秒 · 生成 14 秒 · 参考模式

接图：@image1 = 图A（人物A），@image2 = 图C（场景甲）
接声音：@audio1 = 声A（人物A 的声音）　← 没有真声就不写这一行

```
14秒，9:16竖屏。（主体 + 核心动作，一句）

@image1 是角色设定图，三格是同一个人（左格定脸，中格定衣服，右格定背面），只参考人物，不要画出格子、分隔线和灰底。
@image1 为…，全片保持同一张脸、同一套衣服：（外形，每段一字不差）
场景参考 @image2：（场景一句）
灯光：……

0–3s：主体 …｜动作 …｜运镜 …｜音效 …
3–8s：切到…｜动作 …｜光影 …｜运镜 …

声音：（环境声）。台词都只讲一次。
0–3s 某某用（语气）的语气说：「……」

写实：真实实拍质感，皮肤看得到毛孔和自然光影，不要磨皮、美颜、塑料感或 CG 感。动作简单、一步一步做，一拍只有一个运镜。人物、道具、场景每拍都照上面的描述，不变脸、不换衣服。
不要：字幕、画面上任何字和数字、logo 变形、水印、多余手指、变脸、穿模。（再加这段最容易错的一两条）
```

分拍的 6 要素是：主体｜动作｜场景｜光影｜运镜｜音效，跟段首一样的省略。最后两行「写实」「不要」是固定结尾，每段都带，原样照抄。

衔接点：这一段结尾停在什么画面、人物什么状态（下一段从这里接）。

标题里的「生成 N 秒」和「参考模式 / 首帧模式」，搭 studio 画布的脚本会读，格式不要改。
````

## 写法要点

- 提示词放代码块，一段一个，用户能整段复制。
- 每段标题写清：对应原片哪几秒、生成几秒（整数）、用参考模式还是首帧模式、接哪几张图。
- 原片里同一个镜头出现两次（回忆、回扣），不要生成两次，在后制清单里写「复用第 X 段的 X–X 秒」。
- 待用户补的内容统一写成 `【填：…】`，交付时把所有待填项在最后列一遍。
