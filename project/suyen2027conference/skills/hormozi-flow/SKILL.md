## 0. 跟别的 skill 的分工

| 管什么 | 用哪个 |

## 1. 骨架

| 段 | 大约在哪 | 要做到的事 | 观众心里在问 |
|---|---|---|---|
| **Hook** | 0–3 秒 | 讲出「这跟你有关 + 你会得到什么」 | 这在讲我吗？ |
| **理由** | 3–8 秒 | 马上给一个留下来的理由：把痛讲深一层，或一句她有资格讲的证明 | 凭什么听你的？ |
| **Retain** | 中段 | 清单／步骤／故事往前推；每段结尾留一个没讲完的点 | 下一个是什么？ |
| **Reward（干货）** | 后段 | 把 Hook 答应的东西**真的给出来**，具体到看完就能用 | 我学到了吗？ |
| **CTA** | 最后 3.2 秒 | 只叫一件事：留言「正能量」（`CtaBehind` 自动有） | 我要做什么？ |

整支 < 60 秒（1.15 倍之后）。

## 2. 流程

### 2.1 收料
1. 原片代号和时间段（C0049–C0060），题目照 `原片目录.md` 写成 `[题目] (C00xx)`。
2. 读逐字稿 `transcripts/C00xx.json`（`segments` 有逐句时间）。whisper 会听错名字和字（林苏妍→**林舒苑**、托→拖），引用时改正。
3. 在 `pipeline/内容片-style.md` 那一支的格子定好 style。

### 2.2 先找干货（硬规则，最先做）
**内容片一定要有干货。** 先在逐字稿里找一句符合下面三条的：
- 是一个**方法、判断法、时间点或具体的提醒**，不是「来大会就知道」。
- 观众看完能讲出「我学到了 ___」。
- 回答得了 Hook 的问题。

**找不到就停下来**，不往下排。交给 Reagan：
```
这支缺干货。Hook 问的是：「___」
原片只讲到：「___」（C00xx 第 __ 秒）
要请林舒苑补录一句，例如：「【填：她的判断方法】」
```
例句只写方向，**不替她编奇门内容**，方法要她本人讲。

### 2.3 挑 Hook
从逐字稿里挑**最痛、最有画面、最想知道答案**的那一句，搬到第 0 秒（冷开场放「结论那句」，跟 `suyen-content-rose` 一样）。常常它在原片第 10 秒以后。
- 合用的类型：点名、是非题、如果…就…、命令、反常识、清单、故事。写法见 `docs/Hormozi-拆解稿-草稿.md` 2.2 节 `【待核对：他那支片用哪几种】`。
- 原片里挑不到 → 用 `hook` skill 出 10 条，Reagan 选；选中的要请她补录，不用 AI 声音。
- 第一句不准是「大家好我是林舒苑」。

### 2.4 排 Retain
- 原片有「几个」就**先讲有几个**（「三样要换」），讲了几个就真的要有几个。
- 每段结尾留半句把人带到下一段（「最难的是第三个」）。原片没有这种句，就放进目录 `IndexPanel` 的锁格，不另外编台词。
- 证明（年资、帮过几个老板）**只用她讲过的、或 Reagan 给的数字**，插在中段关键处，不放开头念。
- 跟 Hook、干货无关的句子砍掉，宁可短。

### 2.5 交结构表给 Reagan（剪之前）

| 段 | 原片秒数 | 讲的话（改正错字后） | 为什么放这里 |
|---|---|---|---|
| Hook | C00xx 13.9–16.3 | … | … |
| 理由 | … | … | … |
| Retain | … | … | … |
| 干货 | … | … | … |
| CTA | `CtaBehind` | 留言「正能量」 | |

再附：估计长度（原长 ÷ 1.15，扣掉删的停顿）、缺的东西（干货、证明数字）。
**Reagan 点头才剪**；剪完照 `suyen-content-rose` 出分镜检查图，再点头才渲染。

### 2.6 写 caption
```
第一行 = 再讲一次 Hook（feed 里只看得到这行）
中间   = 一句干货的重点，让没看完的人想回去看
最后   = 只叫一件事：留言「正能量」
```
看情况加**一个**（不要全加）：
| 想要 | 加什么 | 例 |
|---|---|---|
| 分享 | 一句能「转给某个人」的话 | 「转给你那个今年要换伙伴的朋友。」 |
| 收藏 | 片里本来就是清单或日期时，点出来 | 「存起来，2027 签约前再看一次。」 |
| 留言 | 一个选择题 | 「你身边的新伙伴是贵人还是小人？」 |

caption 和片里的 CTA 讲同一件事，不要片里叫留言、caption 叫点连结。

## 3. 交片前过 6 关

| 关 | 问自己 |
|---|---|
| Hook 在第 0 秒 | 第一句是不是最痛／最想知道的那句？不是「大家好」 |
| 有干货 | 看完讲得出「我学到了 ___」吗？讲不出来就不交 |
| 兑现 | Hook 问的，干货有答吗？ |
| 数得清 | 讲了「三个」，片里是不是真的有三个？ |
| 是真的 | 数字、案例、学员的事都是她讲的或 Reagan 给的？没有就 `【填：…】` |
| 一件事 | 片里和 caption 都只叫留言「正能量」？ |

## 4. 分寸
- 不编奇门内容、不编数字和见证；不讲「改命」「保证转运」，不拿人的不幸吓人（同 `hook` 的合规）。
- 吓人的 Hook（换错赔一整年）后面一定要给出路，就是干货。
- 名字「林舒苑」，头衔「奇门遁甲战略导师」。
