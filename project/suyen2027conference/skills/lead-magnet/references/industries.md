# 各行业：客人卡在哪、可以送什么

10 个行业。每个给：客人下决定前卡在哪、3–4 个提案方向（形式 + 名字）、下一步通常是什么、红线。

**怎么用**：用户答不出「客人最常问什么」时，拿这里的「卡在哪」给他挑。提案的名字是示范句型，换成用户自己的对象、地方、数字。**名字里的数量（「6 笔钱」「12 项」）是示范，实际几项照用户真的讲得出几项。**

这里写到的手续、部门、费用项目是给你知道该问什么，**具体数字、比率、最新规定一律问用户或请他去官方查**，不要照你记得的写。

找不到用户的行业：看最后一节「其他行业怎么想」。

---

## 1. 房地产（买屋、卖屋、租屋、投资）

**卡在哪**：不知道自己贷得到多少；只算了头期，不知道还有律师费、印花税、估价费这些；新盘和二手屋的流程不一样；怕买错地点；签了 SPA 才发现有东西没问。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 价钱表 | 《第一间屋子：除了头期，还要准备的 6 笔钱》 | 首购族 |
| 步骤图 | 《买二手屋从看屋到拿锁匙：7 步、每步多久》 | 第一次买二手屋 |
| 必问问题 | 《去看新盘 showroom，要问 sales 的 9 个问题》 | 看新盘的人 |
| 清单 | 《看屋那天要拍的 10 个地方》 | 自住买家 |
| 对比表 | 《租还是买？月入 5 千到 8 千的 5 个问题》 | 在想要不要买的人 |
| 自测 | 《申请房贷之前：6 题看你现在批不批得到》 | 准备贷款的人 |

**下一步**：WhatsApp 帮他算能贷多少 / 约看屋 / 发适合他预算的单位。

**红线**：不写「保证增值」「稳赚」「一定批贷款」；贷款资格只讲银行会看什么（收入、债务、CCRIS / CTOS 记录），不讲「我帮你过」；利率、印花税、津贴和豁免常改，一定问用户最新的并标日期；租金回酬只写真的成交例子。新盘的数字用发展商给的正式资料。

## 2. 买卖车（新车、二手车、recond）

**卡在哪**：新车还是二手；月供以外每个月还要多少（保险、路税、保养、油）；二手车怕泡水、撞过、调过里数；不懂过户手续；trade-in 怕被压价；贷款年限怎么选。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 清单 | 《看二手车那天，带去的 12 项检查表》 | 第一次买二手车 |
| 对比表 | 《新车还是二手车？5 个问题帮你决定》 | 预算有限的年轻人 |
| 价钱表 | 《养一辆车一个月真的要多少：月供以外的 5 笔钱》 | 第一次买车 |
| 步骤图 | 《二手车过户：5 步、要带的文件、谁付钱》 | 买卖双方 |
| 避坑 | 《卖车给车行之前，这 4 件事先做，价钱不一样》 | 要卖车 / trade-in 的人 |
| 体验券 | 《免费估价：发 6 张照片，当天回你一个价》 | 要卖车的人 |

**下一步**：WhatsApp 发车的照片估价 / 约试驾 / 帮算月供。

**红线**：不写「保证批贷款」「零头期」除非真的有而且条件写清楚；里数、车龄、车况照实；过户和验车的规定以 JPJ 最新公布为准，标日期；车的画面一定是右舵。

## 3. 修车 / 汽车保养 / 冷气 / 轮胎

**卡在哪**：不知道这次修是不是真的需要；怕被换不用换的零件；不知道大概多少钱；小问题拖到大修；长途、雨季前不知道查什么。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 体验券 | 《免费冷气检查：15 分钟、查 5 个地方》 | 附近的车主 |
| 清单 | 《balik kampung 之前，自己可以先看的 8 样》 | 长途前的车主 |
| 自测 | 《6 个声音和味道：你的车在讲它哪里有问题》 | 所有车主 |
| 价钱表 | 《【车款】保养参考价：每一万公里换什么、大概多少》 | 那款车的车主 |
| 必问问题 | 《师傅说要换零件，先问这 5 句》 | 怕被多收的车主 |

**下一步**：WhatsApp 预约到店 / 发车款和里数报价。本地生意，名字里放地方（「Puchong 车主」）。

**红线**：零件价和整单价分清楚（「零件 RM80」不要被听成「修好 RM80」）；不讲「别家乱换」；免费检查的条件（哪些车款、要不要预约、不修要不要钱）写明。

## 4. 保险（医药卡、人寿、储蓄、意外）

**卡在哪**：不知道自己够不够；公司有保还要不要自己买；保单看不懂；怕买了赔不到；不知道该花收入的多少。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 自测 | 《8 题自测：你家的保障有没有漏洞》 | 有家庭的人 |
| 必问问题 | 《签医药卡之前，要问 agent 的 7 个问题》 | 第一次买 |
| 清单 | 《入院那天要带的文件，和先打给谁》 | 已经有保单的人 |
| 对比表 | 《公司的保险和自己买的，差在这 5 个地方》 | 打工族 |
| 步骤图 | 《理赔从头到尾：5 步、每步要多久》 | 所有保户 |

**下一步**：WhatsApp 发现有保单，帮他看一次（保单检查）。

**红线**（这行最严）：不写「保证回报」「一定赔」「最便宜」；不拿别家公司的产品比；不讲具体保费和回酬，除非是公司批准的正式说明；不拿疾病和死亡吓人；资料上写清楚负责人的名字和所属公司。很多保险公司规定代理的宣传资料要先给公司过目：**提醒用户发之前问一下自己的公司。**

## 5. 遗嘱 / 信托 / 产业信托 / 保险信托

**卡在哪**：觉得自己还年轻、钱不多，不需要；不懂遗嘱和信托差在哪；不知道没安排的话家人要走什么手续、等多久；有孩子、有生意、有两间屋子的人不知道从哪里开始。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 对比表 | 《遗嘱还是信托？5 个问题看你需要哪一个》 | 有资产的中年人 |
| 自测 | 《7 题自测：你现在走了，家人拿不拿得到钱》 | 有孩子的父母 |
| 步骤图 | 《没有立遗嘱，家人要走的手续：一步一步讲》 | 还没安排的人 |
| 清单 | 《去见规划师之前，先列好这 4 张单》（资产、保单、户口、受益人） | 准备安排的人 |
| 必问问题 | 《设立信托之前要问的 8 个问题》 | 在比较的人 |

**下一步**：WhatsApp 约一次免费的资产盘点。

**红线**：这是法律和财务的事，**法律怎么分、要多久、收多少费、最低多少钱可以开，一律用用户公司的正式资料或请他确认，不照你记得的写**（遗嘱和信托差在哪，也是用用户平时讲给客人听的那一套，不是你的）；对比表和自测只写「你的情况是哪一种」，不写「你应该选哪个」，最后固定一句「问过规划师或律师才决定」；资料上写清楚负责人和所属公司，**发之前提醒用户问公司要不要先过目**；写明「这份资料是一般说明，不是法律意见」；不写「保证避税」「资产一定安全」；穆斯林和非穆斯林的继承规矩不同，资料要讲明是写给谁的；不拿「你死了以后」当吓人的标题，讲「家人」「安排」。

## 6. 护肤 / 美容 / 医美 / 保健品

**卡在哪**：不知道自己是哪种皮肤；买了很多没效；怕敏感、怕烂脸；不知道步骤和先后；做疗程怕被推销配套。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 自测 | 《6 题分出你的皮肤类型，和早晚各用什么》 | 不懂自己肤质的人 |
| 步骤图 | 《早上 4 步、晚上 5 步：先后次序不要错》 | 护肤新手 |
| 避坑 | 《这 5 样东西不要一起用》 | 已经在用很多产品的人 |
| 清单 | 《第一次做脸之前，要先告诉美容师的 6 件事》 | 第一次做疗程 |
| 体验券 | 《免费皮肤检测：20 分钟，不买也可以》 | 附近的客人 |

**下一步**：WhatsApp 发素颜照做免费分析 / 预约体验。

**红线**：不写「治好」「根治」「祛斑」「7 天见效」；不用前后对比照当保证；不下诊断，严重的写「建议看皮肤科医生」；产品只讲成分是做什么的，不讲治病；化妆品要有 KKM 的 notification 号码，保健品不讲疗效：用户的产品有没有，问他。

## 7. 教育 / 补习 / 才艺班 / 升学

**卡在哪**：家长不知道孩子是不会还是不肯读；不知道几时开始补才不迟；国中、独中、国际学校不会选；怕补了没用；SPM、UEC、IGCSE 之后的路不清楚。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 自测 | 《8 题看孩子是「不会」还是「不肯」》 | 小学、中学家长 |
| 对比表 | 《国中、独中、国际学校：比这 6 样》 | 六年级家长 |
| 清单 | 《上一年级前，这 10 样先准备》 | 幼儿园家长 |
| 步骤图 | 《考试前 8 个礼拜的温习表》（空白可填） | 应考生和家长 |
| 体验券 | 《免费试听一堂 + 一份程度评估》 | 附近的家长 |

**下一步**：WhatsApp 约试听 / 做一次免费程度评估。

**红线**：不写「保证 A」「保证进步」；成绩例子要真的、家长同意，不露孩子的全名和脸；不贬低学校和老师；学费、课程纲要的改动以学校和教育部公布为准。

## 8. 摄影 / 拍摄 / 影片制作

**卡在哪**：不懂价钱为什么差那么多；不知道配套包什么（几个小时、几张、修不修图、几时交）；怕成品跟作品集不一样；公司拍片不知道要先准备什么。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 必问问题 | 《请婚礼摄影师之前，要问的 8 个问题》 | 准新人 |
| 价钱表 | 《3 种配套各包什么：看这张表就不会比错》 | 在比价的客人 |
| 清单 | 《拍摄前一天：衣服、地点、时间的 9 项准备》 | 已经订的客人、还在考虑的 |
| 模板 | 《公司拍宣传片之前，先填好这张 brief》 | 企业客户 |
| 步骤图 | 《从订金到拿片：6 步、每步几天》 | 所有客人 |

**下一步**：WhatsApp 发日期和地点，回他一个报价 / 约一次 15 分钟的通话。

**红线**：作品只用自己拍的、客人同意公开的；交件日期写做得到的；价钱表标日期。

## 9. 交通服务（包车、机场接送、出租车、旅游用车、搬运）

**卡在哪**：不知道价钱怎么算（按趟、按小时、按公里）；怕临时加钱（过路费、等候、深夜）；怕司机不来；人多行李多不知道订什么车；长途、跨州、去机场要抓多少时间。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 价钱表 | 《【地区】去 KLIA 接送价目表：几个人、几件行李、订哪种车》 | 要去机场的人 |
| 清单 | 《包车出游之前，要跟司机讲清楚的 7 件事》 | 家庭、公司出游 |
| 步骤图 | 《赶飞机：几点起飞，几点要出门》（一张对照表） | 要去机场的人 |
| 避坑 | 《订车最常被加钱的 4 个地方，订之前先问》 | 第一次包车 |
| 体验券 | 《第一次订车：免等候费 30 分钟》 | 新客人 |

**下一步**：WhatsApp 发日期、时间、地点、人数，马上回价。

**红线**：价钱写明包不包过路费、泊车、等候；车和司机的执照、保险要齐全才写「合法」「有保险」；不贬低 e-hailing 平台。

## 10. 工程 / 建材 / B2B 产品（电梯扶手、玻璃、铝门窗、冷气工程、机器设备）

**卡在哪**：买的人多半是 contractor、建筑师、管理层、屋主，他们要的是**规格对不对、几时交货、合不合规定、坏了谁负责**。不懂怎么写规格去要报价；怕装了不合格被打回头；不知道保养要多久做一次。

| 形式 | 名字示范 | 给谁 |
|---|---|---|
| 模板 | 《要报价之前，先填好这张规格表》（尺寸、材质、数量、地点、期限） | contractor、采购 |
| 清单 | 《验收那天要查的 10 项》 | 屋主、管理层（JMB / MC） |
| 对比表 | 《3 种材质比一比：价钱、耐用、保养》 | 在选材料的人 |
| 步骤图 | 《从量尺寸到装好：5 步、每步几天》 | 所有客户 |
| 清单 | 《每 6 个月保养一次：自己可以先看的 8 样》 | 已经装了的大厦 |

**下一步**：WhatsApp 发图纸或现场照片，回一份报价 / 约现场量尺寸。

**红线**：安全标准和法规（建筑条例、消防、电梯和扶梯的检验）只写「要符合哪一类规定、问谁」，具体条文和检验周期请用户确认；承重、防火等级这些数字只用厂商的正式规格；不写「最便宜」「永久不坏」。

## 其他行业怎么想

照这 4 题想，答案就是提案：

1. **客人第一次 WhatsApp 你，最常问的是哪一句？** → 那句话的答案，做成价钱表或步骤图。
2. **你每次都要重复解释的是什么？** → 写下来，做成清单或对比表。
3. **客人最后悔没早点知道的是什么？** → 做成避坑。
4. **客人离你近、当天就能来吗？** → 是的话，加一张体验券。

| 生意 | 多数卡在 | 先试 |
|---|---|---|
| 餐饮、烘焙、食品 | 订多少、怎么订、几时要订 | 价钱表（订购份量表）、体验券 |
| 装修、室内设计 | 预算、怕被加钱 | 价钱表、避坑、必问问题 |
| 健身、养生、按摩 | 不知道适不适合自己 | 自测、体验券 |
| 零售、电商 | 不会选型号、尺寸 | 对比表、清单 |
| 会计、秘书、法律、贷款顾问 | 不懂流程、怕漏文件 | 步骤图、清单 |
| 旅游、活动策划 | 预算、怕漏安排 | 价钱表、清单 |
| 课程、教练 | 不知道自己在哪个程度 | 自测、模板 |
