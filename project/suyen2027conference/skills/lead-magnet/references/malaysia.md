# 马来西亚写法

Lead magnet 是给马来西亚客人在手机上看的。下面是照本地习惯要守的几样。

## 语言

- **默认马来西亚华语口语**，简体字。讲「屋子」「礼拜」「巴仙」「还没」「可以吗」，不讲「房产」「周」「百分点」「尚未」。
- **本地惯用的英文、马来文词照写**，不要硬翻：SPA、loan、booking、deposit、agent、showroom、trade-in、gas、aircond、geran、balik kampung、pasar malam。客人怎么讲你就怎么写。
- 不要 AI 腔和广告腔：「赋能」「助力」「深度解析」「全方位」「一站式」「终极指南」都不用。
- 语气词写在讯息和片里就好，资料里少用。要用就写中文字（啦、咯、哦），不写 lah、lor。
- **客人群有马来人、印度人或只看英文的华人**（修车、买卖车、交通服务、房地产常是这样）：问用户要不要多做一份 BM 或英文版。内容档翻一份、重跑脚本就好，不要一份里面三种语言挤在一起。
- 名字要短。封面大字在手机上 3–4 行，每行最多 7 个字。

## 钱和数字

- 一律写 **RM**，数字照写：RM350、RM1,200、RM480k、RM1.2 million。资料里是给人看的，不用像片里的口播那样改成「几千块」。
- 价钱一定标是 **哪一年哪一月** 的，和包不包税（SST）。
- 巴仙、利率、津贴、豁免、税率：**只写用户给的**，并写「以 XX 最新公布为准」。这些常在财政预算案之后改。
- 「从 RM… 起」只在真的买得到那个价钱时写。

## 常会提到的本地机构（写对名字，不替它们讲话）

| 事情 | 找谁 / 查哪里 |
|---|---|
| 房贷、车贷、信用记录 | 银行；CCRIS（国家银行）、CTOS |
| 买卖屋子的合约、印花税 | 律师；LHDN |
| 车的过户、路税、驾照 | JPJ；验车是 PUSPAKOM |
| 所得税、扣税项目 | LHDN |
| 公积金提款 | KWSP / EPF |
| 保险、伊斯兰保险 | 保险公司；监管是国家银行（BNM） |
| 化妆品、保健品登记 | KKM（NPRA） |
| 公司注册 | SSM |
| 个人资料 | PDPA |

写法是「这一项去问 XX」，不是「XX 规定一定是…」。

## 怎么送到客人手上

- **WhatsApp 是主场。** 马来西亚人不常开 email。表单一定要 WhatsApp 号码，email 选填；资料用 WhatsApp 发链接。
- PDF 是手机直版（A5），不用放大就看得清楚。一份 2–6 页，档案小，流量少也开得了。
- 最后一页的按钮是 `https://wa.me/60…`（60 后面接号码，去掉最前面的 0，不要空格和横线）。
- 发之前用没登入 Google 的手机开一次链接，确认不用申请权限。

## 各平台怎么叫人拿

| 平台 | 片里怎么讲 | 怎么接 |
|---|---|---|
| Facebook、Instagram | 「留言『清单』，我私讯给你」 | `aigoal-social` 设留言关键字自动私讯 → 私讯里放领取页链接 |
| TikTok | 「留言『清单』」或「看我主页的链接」 | 同上；主页 bio 放领取页链接 |
| 小红书 | **不能**出现 WhatsApp、微信、链接、「私我」「加我」 | 讲「主页群聊里有」，资料放群公告；或请他看主页简介 |
| WhatsApp 旧名单 | 直接发一条讯息问「要不要这份」，回 YES 才发 | `aigoal-whatsapp` |
| 店里 | 柜台放一张 QR | QR 连去领取页 |

- 关键字用一个短词，中文或英文都可以：清单、预算、表、GUIDE、CHECK。片里讲的、caption 写的、系统设的，三处要一模一样。
- 小红书查得严：封面图和资料内页也不要印 WhatsApp 号码的大字。做一份「小红书版」把联络方式拿掉（脚本加 `--no-contact`），在群里才给。

## 时机（名字里放时机，会多很多人拿）

| 几时 | 哪些行业可以用 |
|---|---|
| 农历新年前 | 修车（长途）、美容、摄影（全家福）、餐饮（年饼、捞生）、装修（赶年前完工）、交通（回乡） |
| 开斋节、屠妖节、圣诞前 | 同上，客人群对的话 |
| 年头开学 / 年尾假期 | 教育、交通、摄影（毕业照）、旅游 |
| 年尾（报税年结束前） | 保险（可扣税的项目）、信托规划 |
| 3–4 月报税季 | 会计、保险、房地产（租金收入） |
| 财政预算案公布后 | 房地产、车、保险（政策有改时） |
| 雨季（年尾、东海岸） | 修车、轮胎、屋顶防漏、保险 |
| 发花红、出粮后 | 车、房地产、医美、旅游 |

时机要是真的：过了就把名字改回没有时间的版本，不要让「年前必看」挂到三月。

## 本地客人在意的

- **怕被骗。** 很多人被 scam 过，对「免费」会先怀疑。资料上放真名、真店址或公司名、做了几年。落地页讲明「只用 WhatsApp 发资料给你，不会乱 call」。
- **爱比价。** 价钱表、对比表、「包什么不包什么」特别多人拿。
- **看关系。** 「我帮你看一次」「发来我帮你算」这种一对一的下一步，比「立即购买」好用很多。
- **地方感。** 名字里放地区（Cheras、Penang、JB）、放本地的东西（Myvi、kopitiam、condo、taman），客人一眼知道是讲他。
- **多元种族。** 不拿种族、宗教、口音开玩笑；穆斯林客人相关的（清真、伊斯兰保险、继承）不懂就不写，请用户确认。
