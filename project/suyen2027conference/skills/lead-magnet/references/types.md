# 9 种形式

每种给：什么时候用、名字句型、每页放什么、容易犯的错。页数都不算封面和最后的「下一步」页。

挑形式看一件事：**客人卡在哪一种问题**。

| 客人心里的话 | 用这个 |
|---|---|
| 「我怕漏掉什么」 | 1 清单 |
| 「我怕被骗 / 怕做错」 | 2 避坑 |
| 「到底要准备多少钱」 | 3 价钱表 |
| 「A 和 B 我不会选」 | 4 对比表 |
| 「我不知道要问什么」 | 5 必问问题 |
| 「整个过程是怎样的、要多久」 | 6 步骤图 |
| 「我到底需不需要」 | 7 自测 |
| 「我知道要做，可是不会讲 / 不会写」 | 8 话术模板 |
| 「我想先试一次」（本地到店生意） | 9 体验券 |

---

## 1. 清单（打勾的）

**什么时候用**：客人要做一件有很多小步骤的事，怕漏。最容易做，也最多人拿。

**名字**：《【对象】【时机】要【带 / 查 / 准备】的 N 项清单》
- 《看二手车那天，带去的 12 项检查表》
- 《孩子上一年级前，这 10 样东西先准备》

**每页放**：
- 第 1 页：一句话讲怎么用（「看车那天打开它，一项一项打勾」）+ 第一组 4–6 项
- 第 2–3 页：分组（外观 / 引擎 / 文件），每组 4–6 项，每项一句、看得见摸得到
- 每组后面一个提醒框：这组里最多人漏的是哪一项、为什么

**容易犯的错**：项目太虚（「检查车况」）；超过 20 项；没分组。

## 2. 避坑（N 个最常犯的错）

**什么时候用**：行业里有外行人不知道的坑，用户看过很多客人中。

**名字**：《【做某事】最多人中的 N 个坑》《签【合约】之前，这 N 行字要看到》
- 《第一次装修，报价单上最容易被多算的 5 项》

**每页放**：一个坑一段，固定三句：**坑长什么样** → **为什么会中** → **怎么避**。3–7 个坑。最后一页把「怎么避」收成一张小清单。

**容易犯的错**：只吓人不讲怎么避；讲成「别家都骗人」；坑是编的。每个坑都要是用户真的看过的。

## 3. 价钱表 / 预算表

**什么时候用**：客人最常问「大概多少钱」，而答案是「看情况」。把「看什么情况」摆出来。

**名字**：《【买 / 做某事】除了【大家知道的那笔】，还要准备的 N 笔钱》《【年份】【服务】价钱参考表》
- 《第一间屋子：除了头期，还要准备的 6 笔钱》
- 《婚礼摄影 3 种配套，各包什么、差在哪里》

**每页放**：
- 第 1 页：一张表（项目 · 是什么 · 大概多少 · 几时给）
- 第 2 页：2–3 个例子（「如果你是…，大概是…」）
- 第 3 页：一张空白的「我的预算」表，让他自己填

**容易犯的错**：数字是你估的不是用户给的；没写日期（价钱会变，一定标「截至 X 年 X 月」）；写「最低只要」来钓人。

## 4. 对比表（A 还是 B）

**什么时候用**：客人卡在两三个选择之间（新车还是二手、租还是买、请家教还是去补习中心）。

**名字**：《【A】还是【B】？N 个问题帮你决定》
- 《新车还是二手车？5 个问题，3 分钟知道哪个适合你》

**每页放**：
- 第 1 页：一张对比表（比的项目 4–6 行 × 选项 2–3 栏），格子里写事实，不写「较好」
- 第 2 页：「如果你是这种人 → 选 A」「如果你是那种人 → 选 B」，各 3 条
- 两边都要有选它的理由

**容易犯的错**：其中一栏是自己卖的、写得样样赢。公平地写，客人才信，筛出来的才是对的人。法律、保险、理财这类，第 2 页写「可以考虑…」「先问清楚…」，不替客人下结论。

## 5. 必问问题（买之前要问的 N 题）

**什么时候用**：贵的、专业的、客人不懂怎么判断的东西（保险、信托、装修、工程、补习、摄影）。教他问，他会回来问你。

**名字**：《【签 / 买 / 请】之前，一定要问的 N 个问题》
- 《请婚礼摄影师之前，要问的 8 个问题》

**每页放**：每题三行：**问什么**（照抄就能问）→ **为什么要问** → **好的回答听起来是怎样的**。6–10 题。

**容易犯的错**：问题太专业，客人问不出口；没写「好的回答长怎样」，问了也不会判断。

## 6. 步骤图（从头到尾怎么走）

**什么时候用**：过程长、步骤多、客人不知道自己在哪一步（买屋、过户、申请贷款、理赔、工程安装）。

**名字**：《【做某事】从头到尾 N 步，每一步要多久、要带什么》
- 《二手车过户：5 步、要带的文件、每一步谁付钱》

**每页放**：
- 第 1 页：全部步骤一眼看完（编号步骤）
- 第 2–3 页：每一步一小段：做什么、带什么、大概多久、谁负责
- 一个提醒框：最常卡住的是哪一步

**容易犯的错**：把官方流程当成你讲的。流程和文件会改，标日期，并写「以某某部门最新公布为准」。

## 7. 自测（我需不需要）

**什么时候用**：客人还没觉得自己有问题（保障够不够、孩子要不要补习、皮肤属于哪一种、车要不要大修）。

**名字**：《N 题自测：你的【某样东西】【够不够 / 属于哪一种 / 要不要处理】》
- 《8 题自测：你家的保障有没有漏洞》

**每页放**：
- 第 1 页：5–10 题，每题打勾（是 / 不是）
- 第 2 页：算分表（几个「是」→ 什么情况 → 建议下一步）
- 结果分 3 档就够。最严重那一档的下一步才是「找我」

**容易犯的错**：不管怎么答结果都是「你需要找我」，客人一眼看穿。要有一档是「你目前没问题」。保健、皮肤类不能下诊断，只写「建议给专业的人看」。

## 8. 话术 / 模板（照抄就能用）

**什么时候用**：客人是做生意的或要自己动手的（B2B、教育、求职、房东）。他要的是可以直接用的东西。

**名字**：《N 个可以直接用的【东西】》
- 《跟屋主讲价的 5 句话》
- 《跟供应商要报价之前，这张规格表先填好》

**每页放**：每个模板：什么情况用 → 模板本身（放提醒框里，方便照抄）→ 一句注意。3–7 个。

**容易犯的错**：模板太长；没讲什么时候用。

## 9. 体验券 / 免费检查

**什么时候用**：本地到店的生意（修车、美容、健身、补习试听、摄影试拍）。客人离得近、决定快，送「一次免费的小服务」比送资料有用。

**名字**：《免费【一项具体检查 / 体验】》+ 包什么 + 期限
- 《免费冷气检查：15 分钟、查 5 个地方、不修不用钱》

**每页放**：只做 1–2 页。
- 包什么（3–5 项，写清楚）、不包什么
- 怎么用：WhatsApp 预约 → 出示这张 → 到店
- 条件写明白：有效期、每人几次、哪些车款 / 哪些情况不适用、要不要预约

**容易犯的错**：「免费」后面藏着一定要买；条件没写，到店才讲。期限和名额要是真的。

---

## 两种一起用

- **清单 + 体验券**：清单让他自己查，查到不会的那几项 → 用券来店里查。本地服务很好用。
- **自测 + 价钱表**：先知道自己是哪一种，再看那一种大概多少钱。

一份资料最多两种，再多就变成电子书了。

## 不做的

- 40 页电子书：没人看完，也做不出来。
- 「10 个小贴士」：不筛人，谁都拿。
- 抽奖、送礼物：来的人是要礼物的，不是要买的。
- 需要程式的计算机：落地页平台不能放 JavaScript。改成「价钱表 + 自己填的空白表」，或叫他 WhatsApp 你帮他算。
