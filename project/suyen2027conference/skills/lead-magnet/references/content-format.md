# 内容档怎么写

`build_pdf.py` 读的是一份 `.md`。最上面一段是封面和最后一页的资料，下面是内文。

## 最上面那一段

```
---
title: 看二手车那天 / 带去的 / 12 项检查表
subtitle: 一项一项打勾，不懂车也不会漏
tag: 免费清单
brand: 【品牌名】
author: 【负责人名字】 · 做了 12 年二手车
color: 深蓝
contact: WhatsApp 012-345 6789
note: 资料截至 2026 年 11 月，过户手续以 JPJ 最新公布为准。
next_title: 看到喜欢的车，不确定有没有问题？
next_text: 把车的照片和车牌年份 WhatsApp 给我，我帮你看这 12 项里哪几项要小心。不收费。
next_button: WhatsApp 我
next_link: https://wa.me/60123456789
---
```

| 栏位 | 写什么 | 一定要 |
|---|---|---|
| `title` | 封面大字。用 ` / ` 分成短语，换行只会落在短语之间；每个短语最多 7 个字（标点不算） | 要 |
| `subtitle` | 封面上的一句：怎么用、有什么好处。最多 20 个字 | 建议 |
| `tag` | 封面小标签：免费清单 / 免费指南 / 预算表 / 自测 / 体验券 | 不写就是「免费指南」 |
| `brand` | 品牌或公司名 | 建议 |
| `author` | 负责人 + 一句为什么信他（只写真的）。有挂公司的写上所属公司 | 建议 |
| `color` | 主色。色号（`#1F3A6E`），或色名：深蓝、蓝、墨绿、绿、红、玫红、橙、金、紫、青、咖啡、黑。跟落地页用同一个 | 不写就是深蓝 |
| `contact` | 页脚和封面的联络方式。`author` 加 `contact` 合起来 30 个字以内，封面那一行才不会断 | 建议 |
| `note` | 页脚小字：资料日期、以官方为准 | 有数字、有法规就要 |
| `next_title` `next_text` | 最后一页「下一步」的标题和内文。只叫他做一件事 | 要 |
| `next_button` `next_link` | 按钮的字和链接（`https://wa.me/60…`，60 后面接号码，不要 0 和空格） | 要 |

## 内文

| 写法 | 变成什么 |
|---|---|
| `# 标题` | 一章，自动另起一页（第一个不会） |
| `## 小标题` | 小标 |
| `- [ ] 一项` | 打勾格子 |
| `- 一点` | 圆点 |
| `1. 一步` | 有编号的步骤（圆圈数字） |
| `> 一句提醒` | 提醒框 |
| 表格 `\| 项目 \| 多少 \|` | 表格，第一行是表头 |
| `---` 单独一行 | 换页 |
| `**字**` | 粗体 |
| `【填：…】` `【确认：…】` | 黄色标出来，脚本最后会列出还剩几处 |
| 表格里留空的格子 | 自动加高，给客人手写（「我的预算」这种空白表） |

## 排版的手感

- 一页大约放：打勾 8–10 项，或表格 8 行，或 250 个字。超过就分页；一章不到半页就跟旁边的章合并（少用一个 `#`，改成 `##`）。
- 给客人填的空白表最多 3 栏，不然格子太窄写不下。
- 表格最多 4 栏，格子里最多 15 个字，不然在手机上太挤。
- 每一章开头用一句话讲这页怎么用，不要直接丢清单。
- 提醒框一页最多 2 个。
- 整份 PDF：封面 + 2–5 页内文 + 下一步（跟在最后一章后面，自动另起一页）。

## 例子

```
# 看车之前

带着这张去。不会看的那一项先打问号，回来 WhatsApp 我。

## 文件（先看，不对就不用看车了）

- [ ] 车主的名字和卖车的人是不是同一个
- [ ] 车卡（geran）上的引擎号码，和车上的对不对
- [ ] 路税和保险还有多久

> 最多人漏的是第 1 项。卖车的人不是车主，过户会卡很久。

# 外面和里面

## 外观

- [ ] 四个门的缝，宽度一不一样
- [ ] 车漆有没有一块特别新
```
