# 正文结构

钩子把人留下 3 秒，正文要把钩子的承诺兑现。口播有三种结构，广告有一种。挑一个，不要混。

字数照华语正常语速算：60 秒约 250–300 字，30 秒约 130–150 字。一个汉字算 1，一个英文词或一个数字算 2。表里的秒数是参考，哪一段料多可以挪几秒，总长不变。

---

## 口播 1：干货型（几点式）

**适合**：钩子是痛和怕、好处、好奇、点名。最稳，新手先用这个。

| 秒 | 这段做什么 | 写法 |
|---|---|---|
| 0–3 | 钩子 | 选中的那一句 |
| 3–8 | 为什么听你的 | 一句：年资、看过多少、自己踩过 |
| 8–45 | 2–3 点 | 每点：讲什么 + 为什么 + 一个例子。最重要的放最后，前面先预告（「第三个最多人中」） |
| 45–53 | 一句总结 | 把几点收成一句记得住的话 |
| 53–60 | 叫人做一件事 | 留言关键字 / 私讯 / 到店，加上会得到什么 |

- 点数 2–3 个就够。讲 5 点的 60 秒，每点只剩一句，没人记得。
- 每一点第一句就是结论，不要铺垫。

## 口播 2：故事型

**适合**：钩子是证明、共鸣、反差。用户有一件真的事。

| 秒 | 这段做什么 | 写法 |
|---|---|---|
| 0–3 | 钩子 | 故事里最不寻常的那一刻，或结果 |
| 3–8 | 为什么听你的 | 一句：年资、你在场、是你的客人 |
| 8–15 | 回到开头 | 谁、原来的情况、他要什么 |
| 15–35 | 出事 | 卡住的地方，越具体越好（一句对话、一个数字） |
| 35–50 | 转变 | 做了哪一件事，结果怎样 |
| 50–54 | 一句道理 | 这件事讲明了什么，一句 |
| 54–60 | 叫人做一件事 | 做什么 + 会得到什么 |

- 故事只讲一个人、一件事。
- 客人的故事要问过客人，不露名字和脸，除非他同意。
- 不要把结尾讲成广告；道理讲完，一句带到要人做的事就好。

## 口播 3：对比型

**适合**：钩子是反差、痛和怕。行业里有一个普遍的错做法。

| 秒 | 这段做什么 | 写法 |
|---|---|---|
| 0–3 | 钩子 | 「以为……其实……」或直接讲错的后果 |
| 3–25 | 一般人怎么做 | 讲错的做法，和它带来的结果。讲事，不骂人 |
| 25–50 | 对的怎么做 | 一步一步，2–3 步，每步一句 |
| 50–54 | 差多少 | 两种做法的结果摆在一起，有数字最好 |
| 54–60 | 叫人做一件事 | 做什么 + 会得到什么 |

- 对比的两边要公平，不拿最烂的同行跟最好的自己比。

## 广告：一段正文，配 3 个钩子

广告的人没有关注你，耐心更短。整支 20–30 秒，3–5 秒之后的正文 90–120 个字：

| 秒 | 这段做什么 | 写法 |
|---|---|---|
| 0–3 | 钩子 A / B / C | 三条，来自三个不同的按钮 |
| 3–5 | 过渡句 | 把钩子接到正文。三条钩子各写一句，正文不动 |
| 5–12 | 问题 | 客人现在卡在哪里，一个场景 |
| 12–20 | 你的做法 | 跟别人不同的那一点，只讲一点 |
| 20–25 | 一个证明 | 真的数字、真的客人、真的画面 |
| 25–30 | 叫人做一件事 | 讲清楚按哪里、会得到什么 |

**怎么测**

- 三支片只有 0–5 秒不一样，其他一模一样。这样数据差别才是钩子造成的。
- 钩子用掉的细节，正文的证明就换另一个，不要同一件事讲两次。
- 不写「上礼拜」「昨天」这类会过期的时间词。
- 同样预算、同样受众，各跑几天，看 **3 秒播放率**（看过 3 秒 ÷ 看到的人）。再看有没有人做你要他做的事。
- 留 3 秒播放率最高、又真的有人行动的那条。只高不行动的，是钩子跟正文对不上。
- 下一轮：用赢的那个按钮，再写 3 条不同细节的钩子去测。

## 中途留人的小钩子

60 秒的片至少放 2 个继续看的理由（大约第 15–20 秒和第 35–45 秒）：

- 预告：「第三个最多人中。」「最后一个连师傅都不讲。」
- 转折：「但是问题来了。」「结果他做了一件我没想到的事。」
- 问：「你猜他最后花了多少？」

讲了就要兑现。预告了「最后一个」，最后一个就要真的最重要。

## 结尾叫人做什么

只叫一件，讲清楚做了会得到什么：

- 「留言『清单』，我把这张检查表私讯给你。」
- 「要我帮你看报价单的，私讯我。」
- 「我们在 【地方】，礼拜一到六，来之前先 WhatsApp。」

留言关键字要跟 `aigoal-social` 设的自动私讯关键字一样。
