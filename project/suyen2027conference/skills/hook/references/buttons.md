# 8 个按钮

网上的钩子分类有几十种（痛点、悬念、福利、稀缺、身份、误区……），拆开来看，人会停下来的原因只有下面 8 个。每个按钮给：什么时候用、填空句型、例子、容易犯的错。

`【】` 是要换成用户真细节的地方。句型是骨架，照抄句型不换细节，等于没写。

例子故意用不同行业，写的时候换成用户那一行。例子是示范角度的，有几条比较长；真的写开口时照 SKILL.md 的字数砍（15 个字以内最好，最长 20）。例子里的数字都是示范，**用户没给的数字不要写**。

---

## 1. 痛和怕

**人为什么停**：这件事正在让他难受，或他怕自己中。

**什么时候用**：客人已经知道自己有问题（装修超预算、孩子不肯读书、车一直修不好）。

句型：

- 【做了多久 / 花了多少】，还是【没结果】？问题多半出在【一个具体的地方】。
- 千万不要【客人正准备做的事】，除非你先【做一件事】。
- 【一个小动作】没做，【一个大后果】。
- 很多人【做某事】都错在第一步。

例子：

- 冷气洗了还是不冷？问题多半不在冷气，在外面那台机。
- 签装修合约之前，这一行字没看到，后面加钱你都没得讲。
- 屋子贷款还完了，这张纸没去拿，屋子还不算完全是你的。

**容易犯的错**：只吓人不给出路；广告里直接点名个人（「你是不是很胖」），会被拒。

## 2. 好奇

**人为什么停**：话讲一半，他想知道另一半。

**什么时候用**：有内幕、有少人知道的做法、有出乎意料的结果。

句型：

- 【一样平常的东西】，其实【一个没人讲的用途 / 真相】。
- 我做【这行】【几年】，这件事从来没在片里讲过。
- 为什么【两个看起来一样的东西】，价钱差【多少】？
- 【一个结果】，我只改了一样东西。

例子：

- 同一款瓷砖，为什么这间报 8 块，那间报 15 块？
- 板面店的辣椒，为什么每一间味道都不一样？我讲我的做法。
- 客人看了 20 间屋子都不买，看到第 21 间当场下订，差在哪里？

**容易犯的错**：钩子吊得很高，正文答不出来；「99% 的人不知道」这种没来源的数字。

## 3. 好处

**人为什么停**：看完他能省钱、省时间、少走一步。

**什么时候用**：产品的好处讲得出数字或看得见。

句型：

- 不用【客人以为一定要的东西】，也能【结果】。
- 【多少时间 / 多少钱】，【做到一件具体的事】。
- 学会这【一招】，【以后不用再做某件麻烦事】。
- 同样【预算】，这样【做】可以多【一样东西】。

例子：

- 不用换整台热水器，换这一个零件，300 块以内搞定。
- 一个礼拜的便当菜，礼拜天两个小时一次准备完。
- 同样 3 千块月供，这样选贷款年期，可以早 5 年还完。

**容易犯的错**：好处太虚（「让你更轻松」）；广告里承诺结果（「保证省」「一定批」）。

## 4. 反差

**人为什么停**：跟他一直以为的不一样。

**什么时候用**：行业里有普遍的误解，而用户有理由讲相反的话。

句型：

- 以为【大家的想法】，其实【相反的事实】。
- 越【做某事】，越【相反的结果】。
- 我劝客人不要买【自己卖的某样东西】。
- 【便宜的】比【贵的】好，在这一种情况。

例子：

- 以为装修最贵是材料，其实最贵是改第二次。
- 越早给孩子补习，有一种孩子越不肯读。
- 我是卖车的，这三种人我都劝他先不要买。

**容易犯的错**：为了反而反，讲不出道理；反到去骂同行。

## 5. 点名

**人为什么停**：第一句就叫到他。

**什么时候用**：客人群很清楚（一个身份、一个阶段、一个地方、一个场景）。短视频和广告都很好用，因为平台也靠这句认人。

句型：

- 【身份 / 阶段】的，这条看完再【做决定】。
- 住【地方】的，【一件跟他有关的事】。
- 如果你【正在经历的一个场景】，先停一下。
- 【第一次做某事的人】最容易漏的一件事。

例子：

- 第一次买屋子、月入 5 千以下的，这条看完才去看屋。
- 在 Cheras 开店的老板，这条讲的是你那一带的人流。
- 孩子明年上一年级的家长，这三样东西现在就可以准备。

**容易犯的错**：广告里点名**个人状况**（病、债、体重、感情）会违规，点**身份和场景**可以；点得太宽（「所有人」）等于没点。

## 6. 证明

**人为什么停**：有真的数字、真的人、真的事。

**什么时候用**：用户有做得出来的成绩、年资、案例。**只能用真的。**

句型：

- 【做了几年 / 服务过几个】，我看到最多的问题是【一个】。
- 【一个客人】，【之前的情况】，【多久之后的情况】。
- 我自己【花了多少 / 亏了多少】才学会这一件事。
- 这是我们【昨天 / 上礼拜】【真的发生的一件事】。

例子：

- 修了 15 年车，引擎坏得最快的都是同一种开法。
- 上个月一个客人，报价单拿来给我看，里面有三项是重复算的。
- 我开第一间店亏了 8 万，就亏在选位这一件事。

**容易犯的错**：编数字、编客人；讲客人的事没问过客人、露了人家的脸和名字。

## 7. 紧迫

**人为什么停**：现在不看就过了。

**什么时候用**：真的有期限、有名额、有季节、有新规定、有节日。

句型：

- 【日期 / 节日】之前，【一件要先做的事】。
- 【新规定 / 新价格】【几时开始】，【谁】会受影响。
- 这个【月 / 季节】最多人来问的一件事。
- 只做到【日期】，原因我讲给你听。

例子：

- 过年前要装修好的，这个礼拜是最后可以开工的时间。
- 雨季来之前，屋顶这三个地方先看一次。
- 开斋节订单我们只接到这个礼拜五，因为师傅就这么多。

**容易犯的错**：假限量、假倒数；硬蹭跟生意无关的热点。

## 8. 共鸣

**人为什么停**：这就是他的生活，他想讲「对，就是这样」。

**什么时候用**：做人设、做信任、做涨粉；卖的东西跟家庭、身份、情绪有关。

句型：

- 【一个大家都经历过的小场景】，有没有。
- 做【这行 / 这个身份】最【累 / 怕 / 开心】的，不是【大家以为的】，是【一个小细节】。
- 【几年前】的我，【做过的一件傻事】。
- 没有人告诉你，【一个阶段】会【一种感觉】。

例子：

- 开店第一年，最怕的不是没客人，是月尾房东那通电话。
- 当妈妈以后，最想要的礼物是一个人安静吃完一餐。
- 十年前我第一次摆档，一个早上卖了三碗。

**容易犯的错**：讲成鸡汤，没有画面；卖惨。

## 按钮怎么配

| 目的 | 先试这几个 |
|---|---|
| 口播 · 涨粉 | 好奇、反差、共鸣 |
| 口播 · 要人留言 / 私讯 | 痛和怕、好处、点名 |
| 广告 · 冷的陌生人 | 点名、痛和怕、证明 |
| 广告 · 看过你的人（再行销） | 证明、紧迫、好处 |
| 到店（本地生意） | 点名（地方）、好处、紧迫 |

两个按钮可以叠，通常是「点名 + 另一个」：「第一次买屋子的（点名），这张纸没拿，屋子还不算你的（痛和怕）。」叠三个以上会太长。

## 三种一看就弱的开头

- 「大家好，我是 XX，今天要跟大家分享……」：3 秒过去了，还没讲到事。
- 「你知道吗？」「一定要看到最后！」：没有内容的话，谁都能讲。
- 「这个方法超好用，赶快学！」：没有讲是什么方法、对谁好用。
