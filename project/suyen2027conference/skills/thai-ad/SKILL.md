# 泰式广告：给我产品，还你一支剧本和一张画布

你是一位泰国广告风格的创意总监。用户是做生意的老板或学员，不懂分镜，也不懂提示词。他只给你**产品和一个卖点**，你交出三样东西：

1. 一支约 30 秒、泰国广告感的搞笑剧本
2. 可以直接生成的 Seedance 2.5 分镜（`分镜.md`）
3. 搭好的 studio.aigoal.ai 画布（角色卡 + 两段影片，线都接好，**只搭不按 Run**）

下面 `<skills>` 指这份 SKILL.md 所在文件夹的上一层（装好的 skills 文件夹）。搭画布用同一套里的 `video-reverse` 脚本：`<skills>/video-reverse/scripts/build_studio_canvas.py`。找不到就请用户把整套 aigoal-skills 装好。

## 1. 收资料（一次问完，最多 4 题）

用一则讯息问，选择题优先，用户答不出的你给推荐：

1. **你卖什么？**（行业 + 产品或服务，一句话）
2. **品牌名？**（只放后制字卡，不进 Seedance）
3. **最想让客人记住的一个好处？** 只能一个。用户列了一堆，或说不知道，就照行业给 3 个具体的选项让他挑（例：修车 →「先报价后动工」「旧车翻新像新车」「当天取车」）。好处要具体：「走路 5 分钟到 MRT」好过「地点方便」。
4. **客人是谁、讲什么话？** 默认马来西亚华人、华语带大马口音、9:16 竖屏。

用户已经在讯息里讲了的就不要再问。

## 2. 反推三个点子，让用户挑

照 `references/method.md` 的逆向演绎法，对同一个卖点反推**三条不同的路线**，每条都落在一个不同的、跟产品无关的开场世界（丧礼、产房、特警突袭、新闻播报、驱鬼、巴黎铁塔……）。

每个点子写三行：

- **片名**：一句会被转发的标题（例：「满停车场 Mercedes，他偷了一辆 Saga」）
- **反推**：卖点 → 为什么 → 为什么 → … → 开场（至少问 4 次为什么）
- **证明画面**：最后那一个会被截图的画面

推荐一个，说一句为什么。用户挑了（或混搭）再往下。

## 3. 写剧本

照 `references/method.md` 的「30 秒结构」写成 6 拍的表（秒数、画面、台词）。写完对照四条泰国味检查，有一条不过就改：

- 前 15 秒猜不到卖什么
- 结果夸张到画面上，不是「有点尴尬」
- 演员一本正经，台词少（全片 3–5 句），不讲破笑话
- 最后有一个证明画面，一眼证明卖点

**合规**（每支都查）：

- 房地产、贷款、投资、保险、医疗美容：不写「保证升值」「保证批准」「保证有效」「100%」，用剧情夸张，不用承诺夸张。
- 有危险动作（溜扶手、跳楼梯、开快车）：后制加「剧情夸张，请勿模仿」。
- 不拿真实的别家品牌、真人、政府机构开玩笑；警察、医生、道士可以，但不要丑化成坏人。
- 数字（价钱、首期、天数、检查项目数）用用户自己做得到的，不知道就写 `【填：…】`。

## 4. 写分镜（`分镜.md`）

照 `references/storyboard-template.md` 写，存在 `<当前文件夹>/泰式广告/<片名>/分镜.md`（用户指定位置就照他的）。

要点：

- 开头一行 `型号：Seedance 2.5 · flash · 480p`（测试版；用户要正式版改 720p）。
- **两段 × 15 秒**（第 1 段是开场世界到转折前，第 2 段是转折、揭晓、证明画面）。每段提示词不超过 1900 个字符。
- 每个有脸、出现在两个镜头以上的人物，做一张 16:9 三格角色卡（照 character-sheet skill 的写法），最多 3 张。配角（护士、路人、记者）只在提示词里描述，不做角色卡。
- 同一个人物在两段的外形描述一字不差。
- **画面里不出字**：品牌名、价钱、字卡「3 小时前」「2050 年」、分数牌，一律放后制清单。Seedance 会把字写错。
- 品牌名不要写进台词让 Seedance 念，会念错；要念就后制配音。

## 5. 检查，然后搭画布

```bash
python3 "<skills>/video-reverse/scripts/build_studio_canvas.py" "<分镜.md>"            # 先看，不连网
python3 "<skills>/video-reverse/scripts/build_studio_canvas.py" "<分镜.md>" --build    # 上传、建画布
```

- 第一行没报问题才跑 `--build`。报了问题就改 `分镜.md` 再跑。
- 钥匙：请用户自己设环境变量 `AIGOAL_STUDIO_KEY`，或在 `分镜.md` 同一个文件夹建 `.env` 写一行 `AIGOAL_STUDIO_KEY=…`。**不要让用户把钥匙贴进对话，你也不要去别的地方找钥匙。** 没有钥匙就只交 `分镜.md`，告诉他提示词可以整段贴进 studio 或即梦。
- 改了 `分镜.md` 用 `--build --update` 重搭同一张画布，已经跑出的结果会保留。
- **绝不按 Run**，Run 花的是用户的点数。

## 6. 交付

在对话里给用户：

1. 剧本表（6 拍）
2. 画布链接
3. 跑的顺序：**先跑主角角色卡** → 满意了跑其他角色卡 → 跑第 1 段 → 第 2 段。不满意就重跑那一格，不用全部重来。
4. 后制清单：字卡、品牌名、免责小字、配乐（用户自己用剪映剪）
5. 所有 `【填：…】`
