# 四个平台的文案格式

全部照 SKILL.md B1 的骨架：**钩 → 拉 → 转 → 推**。同一版内容，按平台改长短和格式。

| | Instagram | Facebook | WhatsApp | Telegram |
|---|---|---|---|---|
| 配图 | reels（封面 9:16） | 方图 1:1 或 reels | 方图 1:1 | 方图 1:1 |
| 被截前看得到 | 约第 1 行（~40 字后出「更多」） | 前 2–3 行 | 预览只露 1 行 | 整段 |
| 长度（不算 tag、链接） | ≤ 80 字 | ≤ 120 字 | ≤ 60 字 | ≤ 100 字 |
| 推去哪 | 留言一个字 / 看完整支 | 去 IG 看完整支 / 留言 | 去 IG 看完整支（链接） | 去 IG 看完整支（链接） |
| 格式 | 纯文字；换行就是空行 | 纯文字 | `*粗体*` 只给第 1 行 | `**粗体**` 只给第 1 行 |
| hashtag | 3–5 个，放最后 | 0–2 个 | 不放 | 不放 |
| 表情 | ≤ 2 | ≤ 2 | ≤ 1 | ≤ 1 |

## Instagram

```
<钩：一句，≤ 16 字，第一个字就要有力>

<拉：2–3 句，一句一行>

<转：1–2 句>

<推：留言「XX」，我把 ___ 发给你 👇>   ← 送的东西要真的有

#林舒苑 #奇门遁甲 #<题目关键字> #马来西亚 #<年份>
```

- 第一行就是全部：手机上只看到这一行，没吸引就不会点「更多」。
- 留言关键字用**海报上的字**（例：海报写 2027 → 留言「2027」），人看完封面就知道要打什么。
- 固定 tag：`#林舒苑 #奇门遁甲 #MasterSuyen`，再加 1–2 个题目 tag。不要 tag 一大堆。

## Facebook

```
<钩>
<拉 2–3 句>

<转>

👉 完整影片在 IG：<链接>    或    留言「XX」
```

- FB 的人年纪比较大、比较肯读，可以多 1–2 句「拉」，但还是一句一行。
- 链接放在最后一行，不放第一行（放前面 FB 会把它变大卡片盖掉文字）。

## WhatsApp（群发 / status，配方图）

```
*<钩>*
<转：1 句>
👉 <IG reels 链接>
```

- 3 行就够。图已经讲了，文字只负责「点进去」。
- 群发的整套预热讯息不是这里，去 `skills/suyen-whatsapp/`。

## Telegram（频道，配方图）

```
**<钩>**

<拉 1–2 句>
<转 1 句>

完整影片 👉 <IG reels 链接>
```

- Telegram 频道的人是自己订阅的，比 WhatsApp 多讲一两句没关系。
- 只放一个链接（多个链接预览会乱）。
