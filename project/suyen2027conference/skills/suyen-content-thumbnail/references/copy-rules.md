# 写法规则：去 AI 化 + 马来西亚口吻

海报字和贴文文案都照这一份。

## 1. 一眼就知道是 AI 写的 —— 黑名单（出现就改）

| 类型 | 不要写 | 改成 |
|---|---|---|
| 空话大词 | 赋能、助力、干货满满、深度解析、全方位、底层逻辑、闭环、颠覆、抓手、打造、引爆 | 讲他会得到什么具体的东西 |
| 开场白 | 大家好、今天来聊聊、你知道吗？、在这个快节奏的时代、随着…的发展 | 直接丢画面或结论 |
| 结尾套话 | 让我们一起…、开启…之旅、不容错过、赶快行动吧、未来可期 | 一个具体动作：「留言 2027」 |
| 书面连接词 | 首先 / 其次 / 最后、总而言之、值得一提的是、不仅…更…、与此同时 | 删掉，用换行 |
| 排比三连 | 「看清方向、把握机遇、成就未来」 | 只留一个，最具体的那个 |
| 符号病 | 每行一个 ✨🔥💯、一堆「！！！」、到处【】「」、—— 破折号 | 全文表情 ≤ 2 个，放在叫他行动那一行 |
| 太工整 | 每句一样长、每段一样结构 | 长短混着：一句 3 个字，下一句 12 个字 |
| 假亲切 | 宝子们、家人们、姐妹们、亲 | 「你」就好 |

**自查方法**：读出来。像在 kopitiam 跟朋友讲话 → OK；像新闻稿、像 PPT → 重写。

## 2. 马来西亚华人口吻

**原则**：底子是简体中文，口气是马来西亚人讲话。**一段最多 1–2 个地方词**，放多了像演戏。

| 用 | 例 |
|---|---|
| 语气词：啦、咯、咧、咩、hor、lah（一段一个） | 「真的会很辛苦咯。」「你还要等咩？」 |
| 本地字 | tahan（撑）、sien（闷/烦）、boss、打工、做生意、拼、geng、jialat（惨，少用） |
| 英文夹杂（本地人本来就这样讲） | confirm、really、OK、set reminder、link、share、comment |
| 讲钱讲生活 | 「钱赚到，人没了」「月头有钱，月尾没钱」「生意淡」「家里的老人」「孩子的学费」 |
| 「酱」= 这样 | 「不是酱的」（少用，只给轻松的贴文） |

不要用：中国大陆网络用语（绝绝子、yyds、破防了、内卷、躺平、打工人、家人们）；台湾用语（超、der、真的假的、蛮）；太文的成语（未雨绸缪、居安思危）——改成大白话「先准备好」。

## 3. 让人有情绪的写法

- **画面 > 道理**：「生意越做越累」✗ →「店开到 11 点，月尾还是不够钱」✓
- **对他讲，不对大家讲**：「很多人…」→「你…」
- **反常识开头**：大家以为好的，你说「但是」；大家怕的，你说「其实」。
- **问句收**：海报最后一格、文案第一句或最后一句，至少一个问句。
- **数字要具体**：「这两年」→「2026 到 2027」；「几件事」→「3 件事」（但只写真的）。
- **短**：能删的字都删。删完再删一次「的」「了」「其实」「真的」。
