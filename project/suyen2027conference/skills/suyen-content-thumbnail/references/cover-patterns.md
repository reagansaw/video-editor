## 1. 共通规律（Suyen 的模板已经照做）

1. **一张图只有一个主角句**，字占画面 40–60%。其他字都比它小一半以上。
2. **2 种字体以内**：一种粗黑（中文）、一种衬线或手写（数字 / 点缀）。
3. **3 层字级**：特大（主句）→ 中（转折）→ 小（补充）。不会有第 4 层。
4. **反差色块托字**：红条、黄底、白框——字压在色块上，任何背景都读得到。
5. **人脸 + 眼神 / 笑**：有脸的封面点击率比纯字高；脸在一边，字在另一边，**互不重叠**。
6. **数字和问号**：「2027」「3 个」「吗？」——数字让人觉得具体，问号让人想知道答案。
7. **网格要统一**：同一个帐号的封面同一套版，主页看起来像一个系列（这就是「锁设计只换字」的原因）。
8. **缩到很小还读得到**：IG 主页一格只有约 1/3 屏宽，WhatsApp 预览更小。缩成 200px 宽还看得懂主句才算过。

## 2. 主句常用句型（Suyen 用得上的）

| 句型 | 例 |
|---|---|
| 好消息 + 但是 | 2028 是黄金年，但你撑得过 2027 吗？ |
| 大家以为 + 其实 | 你以为是运气不好？其实是方向错了 |
| 数字清单 | 2027 一定要避开的 3 个决定 |
| 身份点名 | 做生意的，2027 先看这个 |
| 后果 | 看错这一步，两年白做 |
