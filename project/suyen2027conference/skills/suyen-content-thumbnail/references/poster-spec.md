# 海报规格（照 `examples/ref-2028-*.jpg` 量）

## 1. 设计元素（锁住，不换）

| 元素 | 规格 |
|---|---|
| 底 | 深酒红 → 玫红 → 下方淡桃色渐层；右上紫色光；下方 1/3 青海波底纹（淡） |
| 装饰（在底图里） | 右上地球 + 卫星（「天时」的意思）；左边淡淡的奇门九宫格字盘 |
| 人 | 林舒苑，粉红西装 + 白衫，抱红色罗盘，笑，**放右边**，脸在画面上半 |
| logo | 右上 SUYEN 蝴蝶（透明底） |
| 金字（line1 / line4） | 衬线粗体数字（Didot / Bodoni 类），金渐层（亮黄 → 金 → 深金），**深红棕叠位移做厚度**，不是光晕；line4 斜体 |
| 米金字（line2） | 兰亭黑特粗，奶油 → 淡金渐层 + 同样的厚度 |
| 红条（band） | 毛边笔刷红条（深红 → 红，右端淡出），白色特粗字 |
| 白字（line4_tail） | 白色特粗，小一号，跟在 line4 后面 |
| 金底线 | line4 下面一条两端淡出的金线 |
| 贴纸（sticker） | 米黄毛边纸片：左边红色图标（生肖等）+ 竖线 + 右边 3 行深红字 |

颜色：玫红 `#D2405A`、深玫红 `#A82745`、米黄 `#F7E6C6`、红条 `#C4122F → #E23A3F`、贴纸字 `#9B1C1F`、金 `#FFF8D2 → #FFE07A → #F2B52A → #C9850F`。

## 2. 版位（px，宽 1080）

| line1 | x96 y330 字 230 | x90 y168 字 196 |
| line2 | x84 y560 字 150 | x78 y352 字 142 |
| band | x30 y762 宽 622 高 142，字 100 | x18 y508 宽 612 高 110，字 90 |
| line4 | x58 y918 字 186 | x72 y610 字 172 |
| sticker | x44 y1160 宽 560 高 250 | x66 y826 宽 556 高 196 |
| 护脸框 | x660 y770 220×270 | x770 y330 170×200 |

字都在左边 ~640px 以内；人在右边。**换一张照片 / 底图，第一件事是重量护脸框**（`--debug` 出图看紫框有没有框住脸）。

## 3. 一题出 3 组字（给 Reagan 挑）

同一个重点，换 3 个角度。结构不变：好消息 → 但是 → 问你。

| 角度 | line1 | line2 | band | line4 + tail |
|---|---|---|---|---|
| 运势（参考图） | 2028 | 是黄金年 | 但你撑得过 | 2027 吗？ |
| 钱 | 2027 | 钱更难赚 | 但为什么有人 | 赚更多 |
| 生意 | 2027 | 做生意的 | 先别急着冲 | 看完 再说 |

line4 不一定要数字，中文也可以，但**中文比数字宽，最多 3 个字**（4 个字会碰到脸，脚本会挡）。上面 3 组都出过图，过了检查。

## 4. 换新样板设计时（Reagan 之后会给）

1. 跟设计师要**两个尺寸、关掉所有文字图层**的导出图 → `templates/assets/plate-9x16.png`、`plate-1x1.png`。
   没有设计档 → 把样板图的字擦掉（PS 内容识别 / AI 去字），只当底图用。
2. 用样板原图量 5 格字的位置、字号、颜色 → 改 `poster.html` 的 `LAYOUT` 和 CSS 变数。字的格子数如果不一样，改 `build()` 和 `render-poster.mjs` 的 `LIMIT`。
3. 用样板上原来的字写一个 brief，出图，**跟样板叠在一起比**（差不多才算对好）。
4. 更新这一份的第 1、2 节，换掉 `examples/`。
