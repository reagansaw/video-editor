## 0. 一句话

**Hook 抓人 → Retain 留人 → Reward 兑现 → 只叫人做一件事。**
Hormozi 的说法是：观众每一秒都在问「我为什么还要看下去」，每一段都要回答这个问题。

---

## 1. 整支片的骨架（60 秒竖版为例）

| 段 | 秒数 | 要做到的事 | 观众心里在问 |
|---|---|---|---|
| **Hook** | 0–3 | 讲出「这跟你有关 + 你会得到什么」 | 这在讲我吗？ |
| **理由** | 3–8 | 马上给一个留下来的理由：证明你有资格讲，或者把问题讲得更痛 | 凭什么听你的？ |
| **Retain** | 8–45 | 用清单、步骤或故事往前推，每段结尾留一个没讲完的点 | 下一个是什么？ |
| **Reward** | 45–55 | 把 Hook 答应的东西**真的给出来**，具体到看完就能用 | 我学到了吗？ |
| **CTA** | 最后约 3 秒 | 只叫一件事（Suyen 的是留言「正能量」），讲完就收，不拖。内容片已经有最后 3.2 秒左下角的「正能量」气泡（`CtaBehind`），不用整屏 CTA 卡 | 我要做什么？ |

**Hormozi 的核心观念**：免费的内容要给到观众觉得「这个都免费，收费的一定更好」。他讲「把秘诀送出去，卖的是帮你执行」。
→ 对 Suyen 来说：片里要送一个真的奇门判断方法，大会卖的是「帮你看你自己的年盘」。

## 2. Hook：开头 3 秒

### 2.1 三层同时出（跟现有 `hook` skill 一样）
讲的话、画面上的大字、第一个画面，**三样同一秒出现**，各自都能把人留住。没开声音的人只看得到字，所以字要自己站得住。

### 2.2 Hormozi 常用的几种开口 `【待核对：你那支片用了哪几种】`

| 类型 | 写法 | 套 Suyen |
|---|---|---|
| **点名** | 直接叫出那一群人 | 「做了 20 年的老板，听我讲一句。」 |
| **是非题** | 问一个对方一定答「是」的问题 | 「你今年是不是换了伙伴？」 |
| **如果…就…** | 条件加结果 | 「如果你 2027 要换合作伙伴，先看这三点。」 |
| **命令** | 直接叫他停 | 「签合约之前，先停一下。」 |
| **反常识** | 讲一个跟大家想的相反的事 | 「最会拖你下水的人，通常是你最信的那个。」 |
| **清单** | 先讲有几个 | 「贵人跟小人，差在三个地方。」 |
| **故事** | 从一个场面讲起 | 「有个老板跟我讲，他换错一个伙伴，赔掉一整年。」 |

### 2.3 规矩
- **第一句就是 Hook**，不要「大家好我是林舒苑」。自我介绍放到第 3–8 秒，当作「理由」讲。
- Hook 答应什么，后面就一定要给什么（见第 4 节，C0009 就踩到这个问题）。
- 这一块**直接用现有的 `hook` skill**（8 个按钮 × 一个具体细节），新 skill 不重写，只接上它。

## 3. Retain：中段留人

| 手法 | 做法 |
|---|---|
| **先讲有几个** | 「三个要换」讲了，观众就会等到第三个。讲了几个就真的要有几个 |
| **每段留一个没讲完的点** | 一段讲完，下一句先讲个半句：「第三个最多老板中。」 |
| **砍掉所有喘气** | 停顿、「嗯」、「那」、重讲的句子全剪掉（跳剪）。内容片本来就有删段内停顿 + 1.15 倍（`content/cutlib.py`），方向一样。Hormozi 的片几乎没有空拍 `【待核对：他的剪接密度】` |
| **画面一直在变** | 大约每 3–5 秒变一次：推近、换 B-roll、跳出关键字、白板 `【待核对：间隔几秒】` |
| **证明插在中间** | 不要一开头就念资历；讲到关键处才插一句「我帮 xx 个老板看过年盘」【填：真数字】 |
| **口语、短句** | 一句只讲一件事，念出来不绕口 |

## 4. Reward：兑现

- 观众看完要能讲出**「我学到了 ___」**。讲不出来，这支片就只是广告。
- 给的东西要**具体到能马上用**：一个判断方法、一个问题、一个时间点。
- Reward 一给完就进 CTA，不要再总结一次。

### 用你的原片试一下：[贵人还是拖你下水] (C0009)

**现在的顺序**（逐字稿）：

| 秒 | 讲的 | 问题 |
|---|---|---|
| 3.6–11.9 | 定位要换、取道要换、新伙伴要换，要小心哦 | 开口是清单，但还没讲跟观众有什么关系 |
| 13.9–18.5 | 新伙伴到底是贵人，还是拖你下水的人 | **这句才是 Hook**，放在第 14 秒太慢 |
| 18.5–23.2 | 那一次的换错，赔上的可能是一整年 | 很痛，好用 |
| 23.2–43.4 | 2027 奇门战略大会，年盘拆解…正能量 | 直接卖大会，**没回答「怎么分贵人和小人」** |

**照 Hormozi 改：**

| 段 | 讲的 | 来源 |
|---|---|---|
| Hook | 「新伙伴到底是贵人，还是拖你下水的人？」 | C0009 13.9s |
| 理由 | 「换错一次，赔上的可能是一整年。」 | C0009 18.5s |
| Retain | 「2027 有三样要换：定位、取道、伙伴。最难的是第三个。」 | C0009 3.6s 起，重排 |
| **Reward** | **【缺：一个看贵人的奇门方法，原片没有，要 Suyen 补录一句】** | 要补录 |
| CTA | 大会 + 留言「正能量」 | C0009 23.2s 起 + `suyen-cta` |

→ **结论**：C0009 当**广告**（横版）可以照现在这样，因为广告本来就是卖。要当**内容片**发自然流，就缺 Reward，观众会觉得「被骗来看广告」，比较不会分享。

## 5. 剪辑手法（Hormozi 片常见的样子）对 Suyen 的红线

| Hormozi 常见做法 | Suyen 能不能用 |
|---|---|
| 逐字跳出的大字幕，关键字变色 | ✅ 可以，但**字绝对不盖脸**，放人后层 + `FaceGuard` |
| 跳剪剪掉所有停顿 | ✅ 可以 |
| 每几秒推近一下（punch-in） | ✅ 可以，克制用，不要晃 |
| 白板、道具、写字 | ✅ 可以，换成奇门盘、年盘图 |
| 音效配每个跳出的字 | ⚠️ 只用 `sfx22` / `bgm/` 的音效，**不用 jy21 旧音效** |
| 弹跳、表情符号、卡通贴图 | ❌ **不要卡通动效**（HANDOFF 红线） |
| 发光、阴影做强调 | ❌ 不要阴影光晕 |
| 没有片头，第一格就开讲 | ✅ 要 |
| 结尾接回开头，可以重播 `【待核对】` | ⚠️ 内容片最后 3.2 秒有「正能量」气泡，可以并存，但最后一句要接得回开头，要你决定 |

## 6. 让人留言、分享、收藏

Hormozi 的看法是：人分享一支片，是因为**分享它让自己看起来好**：有眼光、懂很多、关心朋友。

| 想要的动作 | 片里要有什么 | 套 Suyen |
|---|---|---|
| **分享** | 一句话可以「转给某个人」 | 「转给你那个今年要换伙伴的朋友。」 |
| **收藏** | 清单、步骤、日期，以后会再用 | 「2027 三个要换的时间点」 |
| **留言** | 选择题，或者一个要表态的立场 | 「你身边的新伙伴，是贵人还是小人？留言 A 或 B。」 |
| **留言关键字** | 留了能拿到东西 | 「留言正能量」→ **现在留了拿到什么？** `【问 Reagan】` |

### 文案（caption）三段

```
第一行 = 再讲一次 Hook（feed 里只看得到这行）
中间   = 一句 Reward 的重点（让没看完的人也想回去看）
最后   = 只叫一件事（留言正能量 / 转给朋友，选一个）
```

示范（C0009）：
> 新伙伴是贵人，还是拖你下水的人？
> 2027 有三样要换，最难的是第三个。【Reward 那句】
> 留言「正能量」，告诉你 2027 奇门战略大会怎么报名。

1. **新开一个 skill 还是并进 `hook`？**
   我建议**新开**，暂名 `hormozi-flow`，管整支片：骨架、剪辑、留言分享、文案。开头 3 秒那段直接调用 `hook`，不重复写。
2. **内容片一定要有 Reward 吗？** 如果要，像 C0009 这种原片就要 Suyen 补录一句干货。
3. **留言「正能量」要不要给东西？** Hormozi 的做法是留言就私讯一个东西（清单、PDF、报名连结）。现在留了好像什么都拿不到。
4. **第 5 节的 ⚠️ 两项**（音效、结尾回圈）你要怎么定。
5. **这个 skill 管哪些片？** 竖版内容片（C0049–C0060）一定管；横版广告要不要也照这套，还是继续照 HANDOFF.md？

## 8. 片子来了我会核对的

- 他那支片实际的 Hook 是哪一种、几秒结束
- 剪接密度：平均几秒一刀、几秒变一次画面
- 字幕样式：字数、颜色、位置
- 中段用清单还是故事、开了几个没讲完的点
- Reward 在第几秒、CTA 多长、讲什么
- 有没有要人分享 / 收藏的句子
